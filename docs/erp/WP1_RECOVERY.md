## OWNER 현장 점검 — 설치·변경 없이 실행

회사 인트라넷 PC의 일반 PowerShell에 다음을 붙여넣고 결과를 전달한다. 비밀번호·키·환경변수는 출력하지 않는다. 오류가 나도 설치나 재시작하지 않는다.

```powershell
$PSVersionTable.PSVersion
Get-Command docker,wsl,python -ErrorAction SilentlyContinue | Select-Object Name

docker version --format '{{.Server.Version}}'
docker ps --format '{{.Names}} {{.Status}} {{.Ports}}'
wsl --status
Test-NetConnection 127.0.0.1 -Port 8080 -InformationLevel Quiet
```

기대 결과: Docker 서버 버전, 컨테이너 가동상태, WSL 상태, 8080 응답 True/False. 멈추면 Ctrl+C. 조회뿐이므로 복구할 설정 변경 없음. Docker가 정상이라면 이번 추가 Python은 컨테이너에 포함하므로 Windows 호스트에 Python 설치를 요구하지 않는다.
