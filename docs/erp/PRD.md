# ERP 분석: 구현 기준

2026-10-27. 현재 단계: 오프라인 입력 검증. 운영 배포 전.

## 확정 요구사항

- 매출, 상품별 총원가, 손익, 채널별 이익, 재고수량.
- 완제품 도착도 매입단가 + 제조경비/노무비/판매관리비 등 영업외비용 제외 경비 배부.
- 경비는 월별 카테고리 매출 비중, 카테고리 내 상품 매출 비중으로 2단계 배부.
- 매입대금과 도착도 단가에 포함된 비용은 중복 배부하지 않는다.
- 재고 평가는 실제 판매가격 기준의 관리 지표. 매입원가와 구분한다.
- 매주 월요일 09:30 Asia/Seoul, PC 종료로 놓친 실행은 다음 가동 시 보충.
- API 우선, 보고서 다운로드 자동화 대체, 엑셀 업로드 및 캡처 검토 지원.
- 추가 유료 서비스 전제 없음. OWNER는 예외만 검토.

## 불확정 정책과 데이터

판매 파일의 VAT 0 행 의미, 순매출이 0/음수인 상품 배부, 과거 매입단가 선택 정책은 미확정이다. 해당 결과를 확정 손익으로 게시하지 않는다. 단가가 없는 상품의 원가를 0으로 대체하지 않는다. 미래 매입단가를 과거 판매에 적용하지 않는다. 현재 품목 마스터를 과거 시점의 확정 마스터로 간주하지 않는다.

## 구현 순서와 완료 기준

1. 입력 검증 CLI: 원본 수정 없이 필드/금액/합계/코드 연결/재고 대사. 구현 및 테스트.
2. 영속 원본·배치 버전·중복 및 수정 감지, 인증된 업로드와 검토 화면.
3. 원가/월별 비용 배부 엔진, 카테고리 연결과 미확정 표시.
4. 인트라넷 경영 대시보드 및 역할 권한.
5. ERP 계정 연결 검증, 예약 작업과 미실행 보충.
6. 복원/재시작/권한/원천 대사 및 사용자 검수 후 배포.

원본 업무 데이터, 매입단가, 검증 보고서의 실데이터는 공개 저장소에 커밋하지 않는다. 테스트는 합성 데이터만 사용한다.
